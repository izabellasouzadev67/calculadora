# Calculadora 🧮

Este projeto é uma aplicação de calculadora simples baseada na web, desenvolvida utilizando HTML, CSS e JavaScript. Ela permite que os usuários realizem operações aritméticas básicas: adição, subtração, multiplicação e divisão.

## ✨ Funcionalidades

*   **Operações Aritméticas Básicas:** Suporta adição (+), subtração (-), multiplicação (*) e divisão (/).
*   **Interface Intuitiva:** Estrutura HTML simples e intuitiva, com CSS para uma estilização básica.
*   **Resultados em Tempo Real:** Exibe o resultado dos cálculos imediatamente após a realização de uma operação.
*   **Tratamento de Divisão por Zero:** Inclui uma verificação para evitar a divisão por zero, apresentando uma mensagem clara ao usuário.

## 🚀 Tecnologias Utilizadas

*   **HTML:** Para estruturar o conteúdo da página web.
*   **CSS:** Para definir a aparência da calculadora.
*   **JavaScript:** Para processar as entradas do usuário e realizar os cálculos.

## 🛠️ Instalação

Este projeto não requer instalação específica nem dependências externas. Trata-se de uma aplicação web independente.

1.  **Clone o repositório:**
```bash
git clone https://github.com/izabellasouzadev67/calculadora.git
```
2.  **Acesse o diretório do projeto:**
```bash
cd calculadora
```
3.  **Abra o arquivo `index.html` em seu navegador web.**

Não são necessárias ferramentas de build ou gerenciadores de pacotes.

## 📝 Como Usar

1.  **Abra o `index.html`:** Abra o arquivo `index.html` no seu navegador de preferência.
2.  **Insira os números:** Digite o primeiro número no campo "Número 1" e o segundo número no campo "Número 2".
3.  **Realize a operação:** Clique em um dos botões de operação (+, -, *, /) para visualizar o resultado.

**Exemplo:**

*   Insira `10` no campo "Número 1".
*   Insira `5` no campo "Número 2".
*   Clique no botão `+`.
*   O resultado `Resultado: 15` será exibido. ## 📂 Estrutura do Projeto
